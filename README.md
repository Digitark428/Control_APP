# Finance App

## Déploiement sur Vercel

### Option 1 — Via GitHub (recommandé)
1. Push ce dossier sur un repo GitHub
2. Connecte-le sur vercel.com → "New Project"
3. Vercel détecte Vite automatiquement
4. Deploy → c'est en ligne

### Option 2 — Via Vercel CLI
```bash
npm install -g vercel
cd vercel-app
npm install
vercel
```

### Option 3 — Drag & drop
1. `npm install && npm run build`
2. Glisse le dossier `dist/` sur vercel.com/new

## Installer sur iPhone
1. Ouvre l'URL sur Safari
2. Partager → "Sur l'écran d'accueil"
3. L'app se lance en plein écran comme une app native
